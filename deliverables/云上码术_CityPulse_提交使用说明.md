# 云上码术 · CityPulse 热城先知 · 海选提交使用说明

## 一、报名表如何提交

### 1. 附件格式（优先）

上传：`云上码术_CityPulse热城先知_海选补充材料.pdf`

这是评委优先阅读的主附件，15 页内包含：

- 命题理解与业务价值
- 团队能力与已有项目积累
- 数据策略与技术架构
- 历史时间截断回测协议
- 模拟数据分析样本
- 四页产品原型
- 去哪儿经营动作闭环
- 实施计划、风险、合规与参考资料

### 2. 多附件（平台允许时）

第二个附件上传：`CityPulse_数据字典与回测样例.xlsx`

该工作簿用于证明方案不是概念稿，包含参数、候选城市评分、日粒度弱信号样本、特征字典、回测协议、评测看板和参考资料。所有模拟字段均已标注。

### 3. 链接格式

把 `CityPulse_GitHub仓库模板.zip` 解压并推送到 GitHub 或 Gitee，再在报名表链接栏填写仓库地址。建议仓库设为公开可访问，并在提交前用无痕窗口测试。

链接栏可写：

> GitHub/Gitee：代码、数据合同、静态交互原型、回测协议、研究笔记与参考资料（填写实际仓库 URL）

不要填写无法打开的占位链接。

## 二、材料包内容

| 文件 | 用途 |
|---|---|
| `云上码术_CityPulse热城先知_海选补充材料.pdf` | 海选主附件，优先上传 |
| `云上码术_CityPulse热城先知_海选补充材料.pptx` | 可编辑源文件，可继续调整或答辩使用 |

| `云上码术_CityPulse_提交使用说明.md` | 当前提交说明 |

## 三、仓库发布步骤

```bash
git init
git add .
git commit -m "init: CityPulse submission package"
git branch -M main
git remote add origin <实际仓库地址>
git push -u origin main
```

静态原型可直接打开 `index.html`；也可开启 GitHub Pages/Gitee Pages，或在本地运行：

```bash
python -m http.server 8000
```

透明评分基线：

```bash
python src/scoring.py data/city_score_snapshot.csv --output ranked_output.csv
```

## 四、提交前检查

- PDF 能正常打开且共 15 页。
- XLSX 能正常打开，所有模拟数据与目标指标均有明确说明。
- 仓库在无痕窗口可以访问，README 图片可以显示。
- 不把模拟候选城市写成真实预测。
- 不把 Hit@5、提前量等目标门槛写成已取得成绩。
- 不暗示已经取得去哪儿内部数据授权。
- 报名表 Part 1、Part 2 与附件中的项目名称、技术路线一致。

## 五、真实性声明

当前候选城市、排名、分数与回测曲线均为“模拟数据 / 方法演示”，用于证明数据合同、评分逻辑、产品界面与验证流程，不构成真实城市预测。正式结果必须基于合法获取的数据，按照 `available_at` 和严格时间截断协议重新生成，并绑定数据、特征、模型和代码版本。
