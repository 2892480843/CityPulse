# 命题洞察对照

记录赛题洞察与平台实现的对应关系，作为评审与迭代的对照表。

## 洞察 1：海量社交内容中的有效信号识别 + 一两周预测窗口

- **预测窗口**：平台原生支持 7 / 14 / 30 天窗口（`POST /api/v1/prediction-runs`），7/14 天正中"一两周"的命题窗口。
- **社交内容细分**：数据合同在 `content_growth`（内容量增速）之上新增 `content_interaction_growth`（点赞/评论/转发等互动增速）作为可选采集指标——互动先于发布量反映真实参与，是"有效信号"的第一道筛选面。
- **轻量化信号筛选**：评分引擎新增**窗口动量筛选**（`momentum_ratio`）：近 3 日加权均值 / 窗口基线加权均值，比值 ≥ 1.15 标记"异常加速"（`accelerating`）。计算 O(指标数)，在重排序之前先从 50-300 城中筛出少数加速候选——对应"先筛后评、缩短预测周期"的建议；榜单与导出均带加速标记。
- **信号去噪**：跨源确认（证据完整度阈值）、来源占比（`sourced_share`）、单源指标缺失时的权重重归一化，均为识别"单一热搜噪声"的既有机制。

## 洞察 2：25-35 岁核心用户、00 后增量最快、大学生覆盖率第一

- **数据维度**：数据合同新增 `young_traveler_share`（25 岁以下及大学生客群的估计占比）作为可选采集指标；两者按"采集先行、权重后置"原则进入合同，**不计入 v1 基线权重**——待真实数据接入并完成时间外校准后，随 v2 评分版本发布（保持规格 3.5 的版本不可变原则）。
- **动作模板**：高优先级动作草案的目标客群默认锚定"年轻情侣与摄影客群"，投放主题模板强调城市独特叙事而非通用标题；DeepSeek 生成时同样接收该客群约束。
- **演示面板**：`data/signals_demo_panel.csv` 已含 `young_traveler_share` 列（延吉 62% 起步），上传后即可在证据链与因子视图中查看。
