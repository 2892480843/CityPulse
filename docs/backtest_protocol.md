# 历史回测协议

## 目标
验证系统能否在热点公开爆发前，提前把目标城市推入 Top-K，并控制误报。

## 样本设计
- 正例：淄博烧烤、天水麻辣烫、哈尔滨冰雪游等已知案例。
- 对照：同区域、同季节、相似体量但未出现同等热度跃升的城市。
- 截点：定义公开爆发日 `T0`，分别在 `T0-30 / T0-14 / T0-7` 生成数据快照。

## 防止未来信息泄漏
1. 按 `available_at` 而非事件日期判断信息是否可用。
2. 训练、调参与测试按时间前滚，不随机打散。
3. POI、天气与交通数据保留版本，事后修订不得覆盖历史快照。
4. 大模型摘要只读取截点前证据。
5. 输出数据、特征、模型版本与随机种子。

## 指标
- `Hit@5`、`NDCG@10`
- `Lead Days`
- `False Alerts / 100 city-days`
- `Brier Score / ECE`
- `Evidence Coverage`
- 企业阶段的 `Action Acceptance`

## 通过门槛
`Hit@5 >= 60%`、平均提前量 `>= 7 天`、证据覆盖率 `>= 90%` 均为迭代目标，不是已取得结果。
